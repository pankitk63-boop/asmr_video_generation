# ASMR Video Generation Workflow

Automated end-to-end workflow for generating viral ASMR videos using Google Gemini and Veo 3.

## 📋 Features

- **Automated Content Ideation**: Uses Gemini AI to generate 5 trending ASMR video ideas
- **Smart Prompt Generation**: Converts ideas into optimized video generation prompts
- **Video Generation**: Creates high-quality videos using Google Veo 3
- **State Management**: Tracks completion status in Excel, resumes where it left off
- **Proper Organization**: Videos saved with descriptive names in `output/` folder
- **Comprehensive Logging**: Detailed logs for debugging and monitoring

## 🚀 Usage

### First Run (Generates New Ideas)

```bash
python workflow.py
```

**What happens:**
1. Creates Excel file `asmr_video_ideas.xlsx`
2. Generates 5 ASMR content ideas using Gemini
3. Creates video prompt for first idea
4. Generates video using Veo 3
5. Saves video to `output/` folder
6. Updates Excel with "Completed" status

### Subsequent Runs (Continues Pending Ideas)

```bash
python workflow.py
```

**What happens:**
- Checks Excel for incomplete ideas
- If found: Continues with next pending idea
- If all complete: Generates 5 new ideas and starts fresh

## 📊 Excel Tracking Sheet

The workflow automatically manages `asmr_video_ideas.xlsx`:

| Column | Description |
|--------|-------------|
| **A: Content Idea** | ASMR video concept generated by Gemini |
| **B: Video Generation Prompt** | Optimized prompt for Veo 3 |
| **C: Status** | Pending → In Progress → Completed/Failed |
| **D: Video Filename** | Generated video filename in output/ |

## 🎬 Video Specifications

- **Format**: MP4
- **Aspect Ratio**: 9:16 (Instagram/TikTok optimized)
- **Quality**: 4K Cinematic
- **Average Size**: 15-20 MB per video
- **Duration**: ~5 seconds (Veo 3 default)

## 🔄 Workflow Logic

```
START
  ↓
Load/Create Excel
  ↓
Check for Incomplete Ideas
  ↓
┌─────────────────┬──────────────────┐
│ Has Incomplete? │ All Complete?    │
│      YES        │      NO          │
│      ↓          │      ↓           │
│  Process Next   │  Generate 5 New  │
│  Incomplete     │  Ideas via Gemini│
└────────┬────────┴──────────┬───────┘
         └───────────────────┘
                 ↓
         Get/Generate Prompt
                 ↓
         Generate Video (Veo 3)
                 ↓
         Save to output/
                 ↓
         Update Excel Status
                 ↓
              DONE
```

## 🔧 Troubleshooting

### Video generation fails
- Check GCP credentials are valid
- Verify Vertex AI API is enabled
- Check quota limits in GCP console

### Excel permission errors
- Close Excel file if open
- Check file permissions

### "No ideas generated"
- Verify Gemini API access
- Check internet connection
- Review logs for API errors
